# Game Topology

用于 game / realtime 目标。核心指标：剪影、面数、法线烘焙质量、变形。

---

## 1. 优先级

```text
1. 剪影保持
2. 法线烘焙质量
3. 关节变形
4. 面数预算
5. LOD 可延展性
```

面数永远最后优化，先保证前三项。

---

## 2. 剪影保持

```text
- 低模外轮廓与高模偏差控制在 1–2 像素（按目标分辨率）
- 凸起结构保留足够段数
- 凹槽不能因减面被抹平
- 细长结构（手指、天线）保证最低环线
```

验证：

```text
高模与低模同角度渲染叠加对比
```

---

## 3. 法线烘焙质量

```text
- 低模面法线方向尽量接近高模
- 避免过度锐利的转折（烘焙会丢失体积）
- UV 接缝避开发光/高曲率区域
- 大平面避免不必要的细分
- 硬边需要足够倒角段数承载法线
```

---

## 4. 面数预算

```text
按资产分级确认后写入 state，例如：
主角      30k–80k tris
次要角色  10k–30k tris
道具      1k–5k tris
环境件    按模块
```

以上仅为常见区间，必须与用户确认后使用。

---

## 5. 三角化策略

```text
- 引擎需要三角面时，在导出前统一三角化
- 三角化前保证四边面方向合理
- 避免细长三角形
- 对称区域三角化方向保持一致，避免左右光照差异
```

---

## 6. LOD

```text
- LOD0 保留完整剪影与变形
- LOD1/LOD2 优先删除不可见内部结构与细节
- 关节环线在低 LOD 仍要保留最低数量
- UV 与材质在各 LOD 间保持一致或明确降级策略
```

---

## 7. 关节变形

```text
- 游戏角色关节环线可略少于影视，但不能缺中心环
- 极限动作（跑、跳、攀爬）需测试
- 蒙皮权重空间预留：环线间距不宜过密，避免权重冲突
```

---

## 8. 交付前检查

```text
[ ] 三角面数在预算内
[ ] 剪影偏差可接受
[ ] 无 n-gon 残留
[ ] 无零面积面 / 重复顶点
[ ] 法线方向正确
[ ] 变换已 apply
[ ] UV 接缝位置合理（与 uv 阶段协同）
[ ] 左右对称区域的三角化方向一致
```
