# UV Layout

---

## 1. 接缝放置原则

```text
优先位置：
1. 不可见面 / 内部面
2. 硬边与倒角分界
3. 材质分区边界
4. 服装/装甲覆盖处

避免位置：
- 面部正面、眼周、口周
- 高曲率连续曲面
- 最大变形方向（关节内侧）
- 高光反射主要区域
```

---

## 2. 岛划分

```text
- 面部单独成岛或少数大岛
- 硬表面按平面/圆柱/独立零件拆岛
- 对称部件可共享岛（镜像 UV）以节省空间，但需确认法线/材质一致
- 岛数量不是越少越好：过度合并会导致拉伸
```

---

## 3. 展开方法

```text
angle-based   适合硬表面与多平面结构
conformal     适合有机，拉伸较均匀
minimum stretch 适合已确定接缝、追求最低畸变
```

选择后必须用 stretch 显示验证，不能只看展开结果。

---

## 4. Texel Density

```text
TD（px/m） = texture_size × sqrt(island_uv_area) / sqrt(island_world_area)
```

要求：

```text
- 同一资产偏差 < 10%
- 特写区域可 1.5–2× 并记录
- 不同贴图集之间需换算到同一 TD 基准
```

验证：

```text
用统一 checker 尺寸渲染，所有区域棋盘格应接近正方形且尺寸一致
```

---

## 5. 打包（Pack）

```text
- padding：4–8 px（2K 贴图），mip 需求高时取上限
- 岛方向：主要结构沿 V 轴，避免 90° 旋转混用
- 满铺率：有机 70%+，硬表面 60%+
- 避免长条缝隙造成采样浪费
```

---

## 6. 多贴图集 / UDIM

```text
- 按 texel density 与区域重要性拆分
- 面部/手部优先高密度集
- UDIM 命名统一，避免 tile 编号错位
- 记录每集的用途与尺寸
```

---

## 7. Checker QA 清单

```text
[ ] 无明显拉伸（棋盘格接近正方形）
[ ] texel density 全资产一致（特写区除外，且已记录）
[ ] padding 足够，无相邻岛渗色
[ ] 岛方向一致
[ ] 接缝位于可接受区域
[ ] 无重叠岛（除刻意镜像共享）
[ ] 无零面积岛
```

---

## 8. 常见错误

```text
- 接缝穿过面部导致贴图断裂
- 岛旋转 90° 导致法线贴图方向错乱
- 为省空间把面部与背部合并成一个岛
- 未 apply scale，texel density 计算失真
- padding 不足，低 mip 出现接缝线
```
