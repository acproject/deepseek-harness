# Metal

---

## 1. 基础参数

```text
Metallic    1（纯金属面）
Base color  按金属类型设定反射色
Roughness   0.05–0.6，按表面处理
```

常见参考（线性值，近似）：

```text
铁/钢      0.56, 0.57, 0.58
铝         0.91, 0.92, 0.92
铜         0.95, 0.64, 0.54
金         1.00, 0.71, 0.29
铬         0.55, 0.56, 0.55
```

仅作起点，必须结合参考与灯光验证。

---

## 2. 粗糙度变化

```text
- 大面积均匀抛光 → 低 roughness + 轻微低频变化
- 使用痕迹 → 局部提高 roughness
- 凹槽与缝隙 → 高 roughness + 污渍
- 边缘 → 磨亮（roughness 降低）
```

禁止全表面单一 roughness。

---

## 3. 边缘磨损

```text
遮罩来源：
1. 曲率（curvature）高亮边缘
2. AO 反相
3. 手工遮罩（关键区域）

处理：
- 磨亮：base color 接近裸金属，roughness 降低
- 掉漆：base color 变为底层材质，metallic 下降
```

---

## 4. 划痕与加工痕迹

```text
- 方向性划痕沿使用方向
- 拉丝金属：各向异性 + 方向性法线
- 铸造表面：低频凹凸 + 颗粒
- 焊接缝：几何或法线凸起 + 热变色
```

---

## 5. 污渍与氧化

```text
- 沉积在凹陷、缝隙、朝上表面
- 锈蚀：颜色偏橙红，roughness 高，metallic 降至 0
- 油污：roughness 降低，颜色变暗
```

---

## 6. 常见错误

```text
- 金属 base color 设为灰色但 metallic=0（变成塑料）
- roughness 全表面 0.2（像玩具）
- 磨损均匀铺满
- 划痕方向随机
- 忽略环境反射，只在中性灯光下检查
- 用强高光掩盖表面凹凸缺失
```

---

## 7. 验收

```text
HDRI 下检查：
- 反射是否连续、有无断裂
- 边缘高光是否合理
- 粗糙度变化是否符合使用逻辑
- 凹陷是否有污渍
```
