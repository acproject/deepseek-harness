# Surface Detail

细节的尺度、笔刷与噪点控制。适用于 S3 与材质阶段。

---

## 1. 尺度一致性

```text
同一资产内，同类细节的最小尺度必须统一
例：所有毛孔直径落在 0.5–1.5mm 区间
```

检查方法：

```text
1. 在模型上放置已知尺寸的参考（如 10mm 刻度）
2. 特写渲染，比较细节占比
3. 不同区域抽样比较
```

---

## 2. 三层细节模型

```text
Layer 1  macro     形状级起伏（S1/S2 负责）
Layer 2  meso      褶皱、甲片边缘、布料折痕
Layer 3  micro     毛孔、颗粒、细划痕
```

材质阶段对应：

```text
macro → 大尺度颜色/粗糙度变化
meso  → 中等法线/凹凸
micro → 高频法线细节
```

不要在多个层重复同一频率，会产生“双倍细节”的塑料感。

---

## 3. 笔刷策略

```text
- 大形用大笔刷、低强度
- 细节用小笔刷、多次轻扫，不用一次重压
- 关闭 auto-smooth 或降低其强度，避免细节被抹平
- 使用 alpha 时控制 spacing，避免拖尾
- 沿结构方向运笔（肌肉走向、布料垂坠方向）
```

---

## 4. 噪点控制

```text
禁止：
- 全表面均匀随机噪点
- 高 strength + 小笔刷的“砂纸效果”
- 未按区域差异化的统一细节

要求：
- 疏密有变化
- 关节、摩擦区、边缘更密
- 平坦区域留白
```

---

## 5. 分辨率与性能

```text
细节分辨率 = 最小特征尺寸 × 3 以上
局部加密优先于全局加密
分块雕刻优先于整体 remesh
```

remesh 使用规则：

```text
- remesh 前保存 checkpoint
- remesh 后立即检查主形是否被改变
- 禁止用 remesh 掩盖结构问题
```

---

## 6. 细节与材质的边界

```text
以下通常交给材质/法线贴图，不雕：
- 极细颗粒
- 大面积均匀纹理
- 颜色变化
- 微观划痕（可用贴图更高效）

以下必须雕或做几何：
- 影响轮廓的褶皱
- 需要真实阴影的凹槽
- 特写镜头下可见的边缘破损
```

---

## 7. 特写验收

```text
1. neutral matcap，近距离渲染
2. 检查：颗粒尺度、过渡、pinching、拖尾
3. 移动视角检查是否有方向性 artefact
4. 与参考特写对比
```

不过关则回到对应层修正，不要靠材质掩盖。
