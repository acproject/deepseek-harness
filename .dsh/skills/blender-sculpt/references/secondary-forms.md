# S2 — Secondary Forms

目标：建立可读的解剖/结构层级，让形体从“体块”变成“生物/物体”。

进入条件：

```text
primary_form == pass
```

---

## 1. 角色次级结构

```text
muscle groups     主要肌群体量
bone landmarks    锁骨、胸骨、髂前上棘、尺骨鹰嘴、髌骨等
fat pads          颊部、眼周、掌部
major folds       颈前、腋下、腹股沟、膝后、肘前
facial planes     额、颧、鼻、上颌、下颌的平面转折
eyelids           上睑与下睑的厚度与包裹关系
lips              口轮匝肌、唇珠、唇线
nostrils          鼻翼与鼻孔朝向
armor transitions 装甲与软组织的交界
```

---

## 2. 面部优先顺序

```text
1. 颅骨与面部大平面
2. 眉弓 / 眶缘 / 颧骨
3. 鼻骨 → 鼻翼 → 鼻孔
4. 上颌 / 下颌 / 颏
5. 眼睑与眼球包裹
6. 口轮匝肌与唇
7. 面颊脂肪与法令区
```

理由：后面的结构依赖前面的平面关系。

---

## 3. 肌群体量

```text
- 三角肌 → 覆盖肩关节
- 胸大肌 → 从锁骨到肋弓
- 腹直肌 → 分块但不断裂轮廓
- 背阔肌 → 从腋下到腰
- 斜方肌 → 颈肩过渡
- 臀大肌 → 髋后体积
- 股四头肌 / 腘绳肌 → 大腿前后
- 腓肠肌 → 小腿后侧
```

规则：

```text
肌肉是“体积关系”，不是“线条”
先做体积，再考虑分隔
分隔只在与参考一致时添加
```

---

## 4. 褶皱层级

```text
primary fold   影响轮廓的大褶（颈、腋、腹股沟、膝后）
secondary fold 局部体积挤压形成的褶
tertiary fold  皮肤表层细褶（属于 S3）
```

S2 只处理 primary 与少量 secondary fold。

---

## 5. 判断标准

```text
[ ] 面部结构可读：眼、鼻、口位置与比例正确
[ ] 肌肉过渡自然，无“贴片感”
[ ] 骨点位置正确，强度符合体型
[ ] 褶皱层级有主次，不是均匀分布
[ ] 六视角下形体无矛盾
[ ] 关节处形变预判合理
```

---

## 6. 常见错误

```text
- 肌肉做成独立球体，缺少过渡
- 骨点过度强调，像解剖模型
- 眼睑与眼球关系错误（睑裂过宽/过窄）
- 鼻翼与鼻头比例失调
- 口部做成贴片，缺少口轮匝肌体积
- 褶皱均匀分布，缺少重力与挤压逻辑
- 过早加毛孔掩盖结构问题
```

---

## 7. 本阶段禁止

```text
pores / micro wrinkles / fine scales / scratches / engraving
```
