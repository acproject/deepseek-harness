# S1 — Primary Forms

目标：在最低面数下把大形做对。此阶段不追求好看，只追求正确。

---

## 1. 角色主形体块

```text
cranium      颅骨主体（不含面部细节）
jaw          下颌体、下颌角、颏部
rib cage     胸廓，含胸腔前后深度
pelvis       骨盆与髋部体量
limb masses  上臂、前臂、大腿、小腿的主筒体
hands/feet   手足体积（不分手指数）
```

顺序：

```text
1. 颅骨与下颌 → 头部整体比例
2. 胸廓 → 躯干上段
3. 骨盆 → 躯干下段
4. 四肢主筒 → 长度与粗细
5. 手足 → 末端体积
6. 整体轮廓统一
```

---

## 2. 生物主形体块

```text
body mass / limb proportion / head-body ratio / large anatomical volumes
```

先确定：

```text
- 体型类别（细长 / 粗壮 / 蹲伏 / 直立）
- 重心位置
- 支撑结构（四足 / 双足 / 飞行）
- 主要运动方向的体积分布
```

---

## 3. 判断标准

在 neutral matcap 下，满足以下才算 S1 完成：

```text
[ ] 六视角轮廓与参考一致
[ ] 头身比、肩宽、髋宽、肢体长度在 ±3%
[ ] 主要体块之间的连接自然，无“拼接感”
[ ] 重心位置正确，站姿可信
[ ] 从 5–10 米距离看剪影可识别
[ ] 无材质、无贴图、无法线细节
```

---

## 4. 常见错误

```text
- 头骨过于球形，缺少额骨/颧骨/枕骨的差异
- 胸廓做成圆柱，忽略前后深度与下部肋弓
- 骨盆宽度与肩宽关系错误
- 四肢做成等粗圆柱，忽略近端粗远端细
- 手/脚体积过大或过小
- 过早处理面部，导致头部比例反复
```

---

## 5. 本阶段禁止

```text
wrinkles / pores / scars / veins / skin noise / fine scales / tiny folds
任何材质与贴图
任何微倒角
```
