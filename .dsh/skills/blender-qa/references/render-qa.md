# Render & Bake QA

烘焙、材质、灯光的 artifact 判定。

---

## 1. 烘焙检查

每张图单独判定，不合并。

### Normal

```text
[ ] 方向正确（与引擎约定一致）
[ ] 无接缝黑线
[ ] 无投影错位
[ ] 硬边保留合理
[ ] 无翻转色块
[ ] 法线强度不过度
```

### AO

```text
[ ] 无噪点
[ ] 接触阴影合理
[ ] 无过强全域暗化
```

### Curvature

```text
[ ] 边缘清晰
[ ] 无过曝
[ ] 无噪点
```

### Displacement

```text
[ ] 无阶梯
[ ] 无溢出
[ ] 精度足够
[ ] midlevel 与材质一致
```

---

## 2. 材质检查

```text
[ ] neutral studio 下能量合理
[ ] HDRI 下反射连续
[ ] roughness 有层次
[ ] 金属/非金属区分正确
[ ] 法线方向正确
[ ] 无纯黑/纯白
[ ] 贴图色彩空间正确
[ ] 无“只在一套灯光下正确”
```

---

## 3. 渲染 artifact

```text
噪点      未收敛的采样 → 提高采样或检查光源
萤火虫    高光/玻璃/强反射 → clamp 或调整材质
穿帮      部件缺失、穿插、错误对象
裁切      主体被画面边缘切断
阴影伪影  shadow terminator、peter-panning
色带      8-bit 输出 + 渐变 → 提高位深
闪烁      动画中的采样不一致
```

---

## 4. 构图与可读性

```text
[ ] 主体在画面中有明确视觉重心
[ ] 轮廓在背景上可读
[ ] 关键细节不在暗部或被遮挡
[ ] 无多余元素干扰
[ ] 画面比例符合交付要求
```

---

## 5. 判定规则

```text
- artifact 影响主体识别 → high
- artifact 仅在特写可见 → medium
- 风格化噪点（刻意）需在 state 记录，不算 fail
- 未通过 lookdev 不得出 final render
```

---

## 6. 常见误判

```text
- 用降噪抹掉细节后仍判 pass
- 用暗部掩盖烘焙接缝
- 只在单一灯光下看材质
- 把风格化高光当成过曝
- 忽略色彩管理导致的明度偏差
```

---

## 7. 输出

```text
- 每张贴图的检查结果
- artifact 区域与严重度
- 渲染图路径
- 是否允许进入下一阶段
```
