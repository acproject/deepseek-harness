# Organic Blockout

适用于角色、生物、以及需要雕刻或形变的有机资产。

---

## 1. 基础网格策略

```text
优先：从低面四边面 base mesh 起步（box modeling / 现有 base mesh）
避免：从高密度球体直接雕刻比例
理由：blockout 阶段需要快速、可逆的结构调整
```

面数参考（blockout 阶段）：

```text
角色全身：1k–8k 面
单个肢体：300–1k 面
头部：500–2k 面
```

---

## 2. 比例落实顺序

严格按比例表，从大到小：

```text
1. 总高 / 总宽 / 总深
2. 头身比与头的位置
3. 肩线、髋线、重心线
4. 四肢分段长度与粗细
5. 手足体积
6. 面部大块（颅、颧、颌、鼻）
```

每一步完成后叠参考检查，不通过不进入下一步。

---

## 3. 环线预留

必须在 blockout 就保证后续可变形：

```text
- 肩：3 圈以上，覆盖三角肌起点到肱二头肌
- 肘：2–3 圈，位于关节中心两侧
- 腕：2 圈
- 髋：3 圈
- 膝：3 圈
- 踝：2 圈
- 口：2 圈（口轮匝肌内外）
- 眼：至少 1 圈完整眼睑环
- 手指：每个关节 2 圈
```

不需要在本阶段做精细 edge flow，但**不能缺环**。

---

## 4. 对称

```text
- 默认 Mirror（X 轴），在最终细节前保持
- 非对称设计（疤痕、单侧装备、倾斜姿态）：
  在 mirror apply 之后单独建模
- 检查中心线顶点是否吸附在 x = 0，避免镜像缝隙
```

---

## 5. 常见错误

```text
- 用球体堆叠后不重拓扑，导致后续无法雕刻
- 关节处环线不足，后续形变断裂
- 过早做肌肉细节，比例错误后全部返工
- 参考图透视畸变被当成真实比例
- 中心线未吸附导致镜像后出现裂缝或双线
- 未 apply scale，导致 modifier 与雕刻笔刷比例异常
```

---

## 6. 进入 sculpt 的交接条件

```text
- 比例表所有关键项偏差在 ±3% 内
- 轮廓六视角无结构性问题
- 环线齐全
- scale applied，法线正确
- 无修改器依赖未确定状态
```

不满足则继续 modeling，不进入 sculpt。
