# Topology Guidelines

所有建模/雕刻/重拓扑阶段提交 QA 前的通用拓扑标准。

---

## 1. 基本原则

```text
1. 面数服从形状，不服从均匀
2. 曲率大的地方密，平坦的地方疏
3. 变形区域必须有连续环线
4. 四边面优先，三角/五边只在必要处
5. 极点（pole）放在不变形、不显眼的位置
```

---

## 2. 极点（Pole）

```text
- 一个顶点连接 4 条边 = 常规
- 连接 5 条边 = 五边极点，允许，但避开高曲率与变形区
- 连接 3 条边 = 三边极点，尽量避免
- 禁止连续多个极点形成“星群”
```

极点位置优先级：

```text
安全：平坦区域、隐藏面、非变形区
危险：眼周、口周、关节、硬边、高光反射区
```

---

## 3. 密度参考

```text
面部（film/hero）：足够支持表情变形，眼口周围最密
面部（game）：按法线烘焙质量定，避免过度
躯干四肢：沿长度方向环线均匀，周向按曲率
硬表面：平面最少面，圆角按倒角段数
```

不要用统一四边形尺寸覆盖整模型。

---

## 4. N-gon 与三角面

```text
允许：
- 完全平坦且不参与变形的区域
- 硬表面不可见的内部面（导出前仍需清理）
- 不影响 shading 与细分的局部过渡

禁止：
- 曲面上出现大 n-gon
- 变形区域的 n-gon
- 三角面出现在高光反射的曲面上
- 导出游戏资产时残留未处理 n-gon（除非引擎支持且已验证）
```

---

## 5. 细分（Subdivision）就绪

```text
- 转角处有支撑线，细分后不塌陷
- 无三角面汇聚点
- 无细长面（长宽比 > 4）
- 边界环（border loop）完整
- 细分预览检查后再提交
```

---

## 6. 法线与变换

```text
- 法线统一朝外
- 无翻转面
- rotation / scale 已 apply
- 无负缩放残留
- 无零面积面、无重复顶点、无悬挂顶点
```

---

## 7. 命名与结构

```text
- 对象命名：<asset>_<part>_<lod>
- collection 按功能分组
- 左右对称部件用 _L / _R 后缀
- modifier 保留必要项，其余 apply
```

---

## 8. 提交 QA 前清单

```text
[ ] 无非流形（刻意开放边界除外）
[ ] 无零面积面 / 重复顶点
[ ] 法线正确
[ ] scale applied
[ ] 极点位置安全
[ ] 变形区环线完整
[ ] 面数在预算内
[ ] 命名清晰
```
